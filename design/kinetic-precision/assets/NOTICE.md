# Font And Artwork Provenance

## Bricolage Grotesque

Official source: <https://github.com/google/fonts/tree/main/ofl/bricolagegrotesque>

Original variable font `BricolageGrotesque[opsz,wdth,wght].ttf` is retained as
`bricolage.ttf`; it is not downloaded by the demo page. The runtime uses the
unmodified Latin variable WOFF2 delivered by Google's font API:

<https://fonts.gstatic.com/s/bricolagegrotesque/v9/3y9K6as8bTXq_nANBjzKo3IeZx8z6up5BeSl9D4dj_x9PpZBMlGIInE.woff2>

License: [bricolage-OFL.txt](bricolage-OFL.txt).

## IBM Plex

The existing repository's installed Fontsource dependencies supply:

- `@fontsource-variable/ibm-plex-sans` / Latin weight-variable normal WOFF2.
- `@fontsource/ibm-plex-mono` / Latin 400 normal WOFF2.

Source project: <https://github.com/IBM/plex>

Licenses: [plex-sans-OFL.txt](plex-sans-OFL.txt),
[plex-mono-OFL.txt](plex-mono-OFL.txt).

All fonts are served locally. There are no runtime Google Fonts, analytics,
tracking, remote asset or model requests.

## Artwork

The S monogram, rounded extrusion, bevel mesh, lighting shader and geometric
controls are original code-native assets for this study. No reference-company
logo, illustration, model, texture or website implementation is redistributed.
