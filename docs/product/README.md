# Syndra Product

Syndra helps teams finish the customer work left behind by a software bug.
The first [customer-repair workflow](customer-repair.md) supports purchase-to-access
evidence, proposed corrections, and a working local application demo.

The local execution runtime and Studio also support repository changes, approvals,
verification, and execution evidence.

**Plan. Execute. Approve. Verify. Review. Replay.**
