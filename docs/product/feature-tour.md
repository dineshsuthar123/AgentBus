# Product Capabilities

1. **Bounded execution roles**: planner, coder, verifier, and reviewer have distinct,
   schema-validated responsibilities.
2. **Real autonomy**: the demo changes a real Git repository through managed
   tools rather than animating a scripted dashboard.
3. **Human control**: Maven pauses at an exact revision-bound approval gate.
4. **Safety by construction**: model output is never authorization; local code
   derives capabilities and evaluates deterministic policy.
5. **Failure recovery**: durable attempts survive interruption and carry
   bounded RetryEvidence without rewriting successful history.
6. **Payment relevance**: sequential and concurrent retries test one atomic
   confirmation decision in a high-consequence scenario.
7. **Verification**: repository checks and mandatory final review both gate
   optional publication.
8. **Inspectable evidence**: scoped diffs, audits, traces, and provenance make
   important actions visible.
9. **Honest replay**: captured, simulated, and dispatched behavior is labelled
   with provider/network/process counters.
10. **Execution observatory**: Studio turns a complex runtime into a recognizable
    execution-centered developer experience.
