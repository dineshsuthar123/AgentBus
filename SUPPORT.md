# AgentBus support

AgentBus `0.1.0-alpha.1` is an early developer release without a production
SLA. Use GitHub issues for reproducible bugs and feature requests after
searching existing reports. Use GitHub Discussions, when enabled, for usage
questions. Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

Include `agentbus version`, sanitized `agentbus doctor --json` output, operating
system, Python version, the failing command, and a minimal disposable
repository. Never attach API keys, `.env` files, full prompts, private source,
provider responses, SQLite databases, or unredacted logs.
